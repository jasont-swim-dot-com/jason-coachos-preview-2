# CoachOS Prototype Review

This GitHub Pages build is a team-review prototype using demo data. It is not a production release and does not establish approval of backend architecture, security, data handling, integrations, payments, or notification delivery.

## Review Accounts

- Coach: `demo@coachos.app` / `coachdemo`
- Swimmer: `nina@coachos.app` / `swimmerdemo`

## Sign-Off Checklist

Record each area as **Approved**, **Approved with changes**, or **Not approved**.

1. Primary navigation and overall information architecture.
2. Dashboard hierarchy: coach tasks, plan readiness, completions, and meets.
3. Swimmer roster density, search, status, and attention cues.
4. Swimmer profile organization and coaching context.
5. Performance presentation: adherence, swim volume, RPE, and dryland.
6. Roster planning overview and individual week navigation.
7. Plain-text workout-writing and live distance feedback.
8. Draft, autosave, publish, and swimmer-view terminology.
9. Visual design, typography, color, spacing, and perceived quality.
10. Desktop and mobile usability.

## Approval Gate

Production implementation should begin only after the team confirms the core workflow, visual direction, terminology, and prioritized revision list. Consolidate feedback into one owned decision log rather than implementing conflicting comments individually.

# CoachOS Team Review Prototype

This repository is a static CoachOS prototype for team review. It contains demo data only.

## Publish

1. Open repository **Settings > Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select `main` and `/(root)`.
4. Save and wait for GitHub to display the public Pages URL.

## Demo Accounts

- Coach: `demo@coachos.app` / `coachdemo`
- Swimmer: `nina@coachos.app` / `swimmerdemo`

Reviewer edits persist only in that browser. Clear the site's browser storage to restore the original demo seed. Do not enter real swimmer information.
